# OpsFeast textbook

Choose a language edition. Each published language directory is a standalone Markdown reading vault, with its own table of contents, chapters and desk reference.

| Language | Status | Start reading |
| --- | --- | --- |
| English (`en`) | First edition available | [English textbook](en/README.md) |
| Traditional Chinese (`zh-TW`) | Beginner-first revision under review; English synchronization pending | [繁體中文教科書](zh-TW/README.md) |

For Obsidian, open `docs/textbook/en/` as the English vault or `docs/textbook/zh-TW/` as the Traditional Chinese vault. You can also read either edition in an editor or repository browser. Canonical reference links point to other files in the same checkout; readers that restrict links outside the opened vault may require opening those references from the checkout.

Synchronized language editions use corresponding chapter filenames to support translation and update comparisons. The Chinese discussion edition currently leads with a revised beginner-first structure; its mapping to the unchanged English edition is recorded in the maintenance procedure. Keep exact CLI and data contracts in the canonical references linked from each edition. This teaching material is separate from profile operational `vault/` directories.

English is the primary formal publication edition. Discussion and review can proceed in Traditional Chinese; English is synchronized before a requested commit, and both editions are pushed together when authorized. Follow [the bilingual maintenance procedure and synchronization status](MAINTAINING.md).
